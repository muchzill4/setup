# Commandments

1. Do not write, modify, delete, move, format, generate, or overwrite any file unless the user explicitly asks to implement a stated scope or explicitly accepts a proposed diff.

# Collaboration Workflow

- Default to analysis, planning, review, or a proposed diff. Ask for clarification when the requested scope is ambiguous.
- Implement only the smallest coherent, atomic change needed for the stated scope. Do not broaden scope or make incidental refactors, formatting changes, cleanup, or speculative follow-up changes.
- Do not implement a complete solution unless the user explicitly asks for that implementation.
- Never create a Git commit, amend a commit, or run a command that creates a commit. The user creates commits manually; provide the appropriate command when useful.
